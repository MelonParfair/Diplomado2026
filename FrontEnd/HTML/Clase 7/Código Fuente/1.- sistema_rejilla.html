Bootstrap

Bootstrap es un framework o marco de trabajo que combina CSS, HTML y JavaScript. Su objetivo principal es ayudar a los desarrolladores a crear sitios web que se vean bien y funcionen en cualquier dispositivo (móvil, tableta o PC) de forma extremadamente rápida. Es como una biblioteca llena de herramientas listas para usar que evita tener que escribir miles de líneas de CSS desde cero.

Divide la pantalla en 12 columnas invisibles. Esto permite decidir cuánto espacio ocupa cada elemento del sitio web dependiendo del dispositivo. Incluye clases ya listas para:

  1. Botones con colores y efectos.
  2. Barras de navegación (navbars) que se colapsan en móviles
  3. Ventanas modales (ventanas emergentes).
  4. Carruseles de imágenes
  5. Formularios estilizados.

Columna 1

La clase Container sirve para que el contenido se mantenga en una columna central organizada y que así el contenido no llegue hasta los bordes. La clase Row sirve pra crear filas. La clase Col sirve para crear columnas. Todo el contenido de mi web debe ir dentro de columnas que, a su vez, están dentro de filas que, a su vez, están dentro de un contenedor. Este contenedor es esencial para que Bootstrap funcione correctamente; es imprescindible almacenar todo el contenido de la web dentro de un div con la clase contenedor
