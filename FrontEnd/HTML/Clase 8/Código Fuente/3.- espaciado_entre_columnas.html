La clase g: pertenece al sistema de Gutters (espacios entre columnas) de Bootstrap (específicamente desde la versión 5). Estas clases sirven para controlar de forma muy precisa la separación que hay entre las columnas (.col) dentro de una fila (.row).

  • g-0 Espaciado nulo: Elimina por completo el espacio entre columnas, tanto horizontal como verticalmente.
  • gx Espaciado horizontal: Controla el espacio únicamente en los lados izquierdo y derecho de las columnas (el eje X).
  • gy Espaciado vertical: Controla el espacio únicamente arriba y abajo de las columnas (el eje Y).
  • g-1 4x Mínimo: Un espacio muy sutil, ideal para micro diseños o listas compactas.
  • g-2 8px Pequeño: Una separación ligera, común en cuadrículas de imágenes pequeñas.
  • g-3 16px Por Defecto: Si no pones ninguna clase g, este es el espacio que Bootstrap aplica automáticamente.
  • g-4 24px Grande: Una separación generosa para secciones de contenido o blogs.
  • g-5 48px Máximo: El espacio más grande de la escala, ideal para separar elementos muy visuales.
